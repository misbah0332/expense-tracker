# PRD: Expense Tracker

## 1. Objective
Build a secure, single-user expense management application.

## 2. Core Features
- **Authentication:** Secure login.
- **Expense Management:** Add, view, edit and delete expenses.
- **Categories:** Predefined and custom categories.
- **Expense Details:** Amount, date, category and description.
- **Summary:** Total expenses, category-wise breakdown and date filtering.

## 3. Technology Stack
- Python
- Streamlit (Frontend)
- FastAPI (Backend)
- PostgreSQL (Database)

## 4. Security
- Secure authentication and password storage.
- Backend validation and protected API endpoints.
- Secure secrets management and safe database access.

## 5. Scope and Completion
**Out of scope:** Multiple users, budgets, recurring expenses, bank integrations and AI features.

**Completion criteria:** Core features work correctly, data persists, basic tests pass, and setup instructions are documented.
